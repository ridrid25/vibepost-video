# Задание бригаде: medved-ipoteka (26.10.2026)

Идея заказчицы: Медведь — «ИПОТЕКА — ЭТО НАВСЕГДА?»
Реплика (дословно, слова не менять, можно делить по битам):
«Купил берлогу в ипотеку. Теперь банк владеет мной, моим сном и даже мёдом.»
Площадка ТикТок. Формат дома — как последний промт prompts/homyak-kassa9-3d.json
(3D animation, original character design, vivid saturated colors; JSON с полями
subject / second_characters / props / environment / lighting / light_events /
motion_rule / audio / timeline[{t,line,a,c,hook}] / negative_prompt).

Главный документ: ../ПРИНЦИПЫ_ЗАВОДА.md — при противоречии действует он.

## Правила (кратко, всё обязательно)
- 10,00 с, 9:16. Биты: первый ≤0,8 с, любой ≤1,5 с.
- Первая секунда: бит 0.00 — медведь уже в действии и уже крупно, без входа в кадр
  и разбега; на первом кадре видна странность, ради которой досматривают. Камера уже
  летит к конфликту.
- Речь 4–5 слогов/с (целить 4,9, ровно 5,00 счётчик бракует), фраза в бите ≤6 слов,
  речь кончается до 9,2 с, реплика в промте ровно один раз. Бит с речью >1,5 с — резать.
  В речевом бите челюсть работает: никаких muzzle still / mouth closed / предмет во рту;
  с героем во время речи ничего не делают (толчки, брызги) — только после слова.
  Первое слово — близко к началу (немой кусок заливается выдуманной речью).
- Крючок (правило 61): последние 0,6–1 с (9.2–10.0) — отдельный бит после добивки,
  без речи, крупно: петля / открытый финал / деталь на пересмотр.
- Правило 62–63: сценарист сдаёт строки КРЮЧОК, ПЕРВАЯ СЕКУНДА, ПЕРЕСМОТР, КОММЕНТАРИЙ,
  ПЕРЕСЛАТЬ (конкретный адресат), ГЕРОЙ СЕРИИ, КУЛЬМИНАЦИЯ, ВНИМАНИЕ (≥5 точек через →),
  ПАНЧ (одно слово). Оба персонажа двигаются свободно; в каждом бите одна точка
  внимания (ФОКУС), у каждого предмета в каждом бите назван владелец.
- Камера (59, 60, 64): БОКОВОЙ ПРОЕЗД ЗАПРЕЩЁН — ни ленты, тележки, рельсы, конвейера,
  подноса, камеры, едущей вдоль героя, проезда мимо полок (слова belt, conveyor, rail,
  trolley, cart, tray, dolly, alongside — вне negative_prompt не писать). Остаются:
  камера кружит вокруг героя; мир летит в героя (он на месте, предметы и второстепенные
  проносятся у линзы); герой идёт на камеру (редко). ≥5 динамичных движений камеры
  разного вида, каждое повешено на событие героя; ≥3 приёма из меню оператора по
  моменту сюжета; 4 разных ракурса; передний план в ≥2 битах; один наезд броском.
  Не меньше трёх крупных планов — движением в объектив/телом, не зумом.
  Схема не должна повторять homyak-kassa8 и homyak-kassa9 (там: падение с предметом →
  сквозь губы → рывок снизу → ныряние сверху → дуга → бросок → облёт через плечо →
  бросок в волну → подъём → вид из предмета → спуск к лицу).
  ИМЕНА ПРИЁМОВ КАМЕРЫ В ПРОМТ НЕ ПИСАТЬ (модель вывела «MOUTH IN» надписью) —
  только путь камеры словами.
- Свет (11, 68): ярко, без ночи и темноты, контровой с двух сторон, тёплый ключ на
  морду; насыщенный цвет на герое, герой контрастен простому фону; серое на сером
  запрещено. Берлога — это не повод для темноты: зажечь.
- Звук (66): звук на каждую точку внимания, самый громкий — на кульминацию.
- Тон (17, 66, 67): сухой взрослый чёрный юмор, зритель 25–44, бытовая ситуация
  (ипотека, банк, платёж). Шутка видна без звука: смешное — действие. Без крови и ран,
  без реальных банков/брендов/логотипов, без людей (второстепенные — звери), без
  названий студий. Медведь не милый, без широкой улыбки на панче.
- Надписи: никаких слов, цифр, логотипов на предметах (модель печатает тарабарщину).
- Размер JSON ≤4080 знаков в компактном виде (JSON.stringify без отступов).
