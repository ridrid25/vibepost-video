# Гусь — ТВОЯ ПЕНСИЯ — МЕЧТА ИЛИ СТРАШНЫЙ СОН? (v11, режиссёр)

Основа — сценарий v11: проводы с 40-го этажа, зонтик для коктейля вместо парашюта, яма, часы-надгробие. v10 — только справка. В v10 на 1.0–2.0 гуся тянули из пола на месте. Здесь на 1.0–2.0 два события подряд: рывок кольца и выстрел зонтика, потом волчок. Гусь ни одной секунды не стоит.

Реплики сценариста не менял. Каждое предложение заказчицы — целиком в своём бите, с запасом 0,1–0,3 с по краям. Клюв свободен: зонтик и рюкзак — в крыльях, не у клюва. Внутри длинной реплики два действия, саму реплику не режу.

## Пластика гуся (узнают без подписи)

1. Шея гнётся змеёй: тело крутится волчком, голова остаётся ровной и серьёзной.
2. Шипит с вытянутой шеей без повода. Один раз — на часы, которые падают на него (7.2). Это его натура, и она его губит.
3. Крылья рефлексом раскрываются на 0,1 с и сразу прижимаются обратно к рюкзаку. Первый раз на 1.0, когда раскрывается зонтик: мог улететь. Второй раз на 7.9, из ямы, под часами: раскрыться уже некуда. АНТИДЕЙСТВИЕ: птица не летит, бережёт подарок.
4. Очки съезжают на кончик клюва после удара, он поправляет их кончиком крыла, не выпуская зонтик (5.0).
5. Лапы семенят в воздухе, как будто идёт по полу (0.0–0.6 и на подлёте к земле 3.2).

## Антигерои — работают по гусю физически

- Крот-начальник в сером костюме: машет платочком, держит часы, разжимает лапы над двором, берёт следующие часы. Его действие — источник кульминации.
- Бобр-землекоп в оранжевом жилете: подбегает с лопатой, тормозит, опускает лопату, плашмя хлопает ею по часам на яме. Его действие — перелом 5.7–7.0 и добивка.
- Коллеги в окнах — фон, не точка внимания. Один раз поднимают бокалы, когда гусь пролетает.

Зайца с рюкзаком в крючке не ставлю: 0,8 с не хватит на второго нового зверя. Если у оператора остаётся размер — заяц силуэтом за кротом, без действия.

## Проверка без звука

Гусь падает с башни → дёргает кольцо, вылетает зонтик из коктейля → бьётся о двор и сам выбивает себе яму → землекоп опоздал, лопата не нужна → начальник бросает подарочные часы, они прибивают гуся и ложатся надгробием → сверху видно: весь двор — такие же часы, начальник берёт следующие. Всё читается действием.

Главный исход — часы-надгробие — случается в 8.2, не раньше. Угроза растёт: часы в лапах крота с кадра 0, тень на 6.6, бросок на 7.0.

## ВНИМАНИЕ — точки по высоте

Окно 40-го этажа (верх) → фасад (середина, гусь вниз головой) → нижние окна с бокалом → плитка двора (земля) → яма (ниже земли) → сверху снова вниз: часы с 40-го этажа → яма → взлёт над двором → окно 40-го этажа. Маршрут вертикальный: камера падает вместе с гусем, потом взлетает обратно. Это приём, которого не снять в жизни.
