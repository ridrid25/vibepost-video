# Гусь — ТВОЯ ПЕНСИЯ — МЕЧТА ИЛИ СТРАШНЫЙ СОН? — режиссёр v15

Основа — сценарий v15 (яйцо «65» на дне ямы → яма «66»). v14 — только справка;
механика бобра «поднял на плечо, отвернулся, бросил не глядя» не используется.
Окно 6.8–8.3 (провал v14) занято самым резким действием ролика: взрыв земли,
гусь вылетает из ямы мимо объектива, жёсткая посадка на край.

## Пластика гуся (узнают без подписи)

1. Шея выстреливает вперёд низко над землёй, клюв открыт — шип.
2. Удар крыльями врастопырку: пыль, перья, тело подпрыгивает.
3. Взгляд одним глазом: голова повёрнута боком, резкий наклон.
4. Переваливается враскачку, хвост виляет.
5. Встряхивается всем телом от головы к хвосту.

Антидействие: гусь, который по натуре атакует без повода и умеет летать, весь
ролик вежлив и действует «по правилам»: ловит конверт, лезет по стенке, просит
лопату крылом. Тело выдаёт натуру: шея дважды сама выстреливает в шип на крота.
Первый раз (5.8) гусь гасит шип и превращает в вежливый жест крылом. Второй раз
(7.7) — победный шип с края ямы, ровно перед тем, как край уходит из-под лап.
Встряска тоже дважды: в 0.7 скорлупа на голове не слетает; в 4.8 после съезда
встряхивается — и колпак скорлупы снова на месте.

Крот-чиновник (антигерой): галстук, нарукавники, лопата всегда в лапах. Работает
контактом: роняет конверт, гладит и прячет лопату, рубит дёрн под лапами гуся,
ловит очки гуся.

Крупных планов: 4 (0.00 осколки, 3.80 монета, 7.70 морда в шипе, 9.20 яйцо).
Точки внимания по высоте: дно → край вверху → падение по стенке → дно и щель →
стенка → край → небо → край → провал → дно новой ямы глубже. Камере есть куда
лететь вверх и вниз.

Реплика заказчицы режется на пять кусков по одному на бит: «Говорят, на пенсии»
(0.8–1.7), «жизнь начинается.» (1.7–2.7), «Моя началось,» (2.8–3.7), «как будто в
яме.» (3.8–4.8), «Только без лопаты.» (5.85–6.75). После 6.8 речи нет — добивка
действием. Говорит только гусь; клюв свободен на каждом куске речи (конверт в
крыльях, рвёт клювом только на паузе после «Моя началось,» — если генератор не
успевает, гусь рвёт конверт крылом).

Проверка без звука: вылупился в яме → наверху крот с лопатой → пенсия = одна
монета, и та укатилась → вылезти не может → лопату не дают → вылетел сам → сел
туда, где ждала вторая яма → новое яйцо «66». Шутка читается.
