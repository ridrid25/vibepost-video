# Гусь / пенсия: задание бригаде на новую историю после v5

Статус: **бриф на сценарную переделку; не промпт для Gemini и не отправка в Telegram**.
Источник провала — `gus-pensiya-v5.video-review.md`. Сохраняются просьбы
заказчицы: гусь резко вылетает из ямы, крот оказывается вместо него, одна каска
и один праздничный колпак меняют владельцев; точная исходная реплика —
«Говорят, на пенсии жизнь начинается. Моя началась, как будто в яме. Только без
лопаты.» Никаких новых роликов по этому брифу автоматически не генерировать.

## Вопросы до написания промпта

1. **Досмотр:** какое уже происходящее в первом кадре физическое нападение и
   какая неожиданность к 0,7 с создают вопрос, исход которого зритель узнает
   лишь после 7-й секунды? Первым кадром камера УЖЕ с большой скоростью летит
   к точке контакта; персонаж/зум не подменяют полёт.
2. **Шутка без звука:** что гусь делает против намерения крота? Почему это
   едкая история о «пенсии», а не обычное падение в яму? Один рабочий предмет
   должен стать причиной обоих столкновений, а не декоративным реквизитом.
3. **Пересмотр:** какая *конкретная видимая деталь 0–2 с* в финале получает
   новый смысл? В чём новое последствие на 9,2–10 с после уже показанного
   обмена? Просто повтор «гусь наверху, крот внизу» не принимается.
4. **Реализуемость:** в 10 сек должны ясно читаться причины вылета/падения,
   путь единственной каски и колпака, три смысловых крупных плана и последний
   предметный удар. Если цепочка перегружена, упрощать промежуточные гэги,
   а не сжимать четыре действия в один бит.

## Порядок работы ролей

- Сценарист сначала предлагает 2–3 **разных** беззвучных панча. В каждом:
  «почему досмотреть», «почему пересмотреть», действие, антидействие, антигерой,
  работающий предмет; лучшая идея должна быть смешной без реплики.
- Режиссёр выбирает читаемую причинную цепь: конфликт 0–0,7; нарастание до 7;
  самый сильный обмен 7–9,2; отдельное новое последствие 9,2–10. Для каждого
  бита — одно главное действие и одна точка внимания; статус каски и колпака
  записан по владельцам.
- Оператор ставит разные быстрые **физические** пути камеры к действию, а не
  к пустому интерьеру: резкий полёт с кадра 0, минимум три крупных плана
  (первый конфликт, причина перелома, финальный предмет), сильный параллакс,
  без чёрных краёв. Яркие цвета — на герое все 10 секунд, простой контрастный
  фон. Яма — оранжевая глина без фруктов, если цвет нужен именно ей.
- Критик до промпта вслух отвечает на два вопроса из начала брифа и сравнивает
  кадр 0–2 с с последним. Если второй ответ равен «шапки поменялись», сюжет
  возвращается сценаристу. Счётчик проверяет только формальные признаки и
  не может подтверждать юмор/досмотр.

Приёмка следующего фактического файла отдельно проверяет кадры 0–0,7 с,
три реальных крупных плана, непрерывность одного экземпляра каждого предмета,
новое действие финала и 9:16. Наличие команд в тексте не равно выполнению
видео. Метрики досмотра и пересмотра можно сравнивать только после публикации
принятого варианта; этот дубль для публикации не годится.
