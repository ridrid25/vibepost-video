# medved-ipoteka — сценарист (26.10.2026)

Варианты:
- А. Лиса-банк красной печатью штампует всё в берлоге: ключ, медведя, подушку, мёд.
- Б. Медведь на цепи из ипотечных платежей, лиса тянет цепь.
- В. Лиса будит медведя из спячки будильником и уводит работать.

Беру А и добавляю будильник из В. Почему: красная печать на каждом его предмете видна
без звука. Каждое «владеет» — отдельный удар печати. Слов на предметах нет, только
красный отпечаток лапы.

ГЕРОЙ: бурый медведь, грузный, в растянутой вязаной кофте, морда хмурая, не милая.
Только у медведя ипотека отнимает зимний сон: для него «моим сном» значит всю зиму.
Второстепенная — рыжая лиса-банк: строгий зелёный жилет, в лапе большая красная печать
на длинной ручке. Печать ставит красный отпечаток лисьей лапы, без букв и цифр.

МЕСТО: берлога-квартира в склоне холма, яркий день. Разные зоны для фонов:
1. Круглая красная новая дверь, над ней гвоздь для ключа.
2. Полка с янтарными банками мёда, банки светятся на солнце.
3. Кровать из зелёного мха, на ней полосатая подушка.
4. Пень-тумбочка, на нём круглый медный будильник.
5. Солнечный луч падает через дыру в своде, за дверью белый снежный лес.

РЕПЛИКИ (дословно, деление по битам):
  1. «Купил берлогу» — хук
  2. «в ипотеку.»
  3. «Теперь банк владеет мной,»
  4. «моим сном»
  5. «и даже мёдом.» — панч
  Добивка — действием, без слов (сухой взгляд в объектив с пустой липкой лапой).

БЕЗ ЗВУКА: на всё, что медведь показывает как своё, сразу шлёпается красная лисья печать.
В конце лиса через соломинку выпивает его мёд, а медведь облизывает пустую лапу.

ПРЕДМЕТ: большой золотой ключ от берлоги. Через него идёт сквозная деталь. Вторая деталь —
красная печать лисы.
