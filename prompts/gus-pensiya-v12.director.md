# Гусь — ТВОЯ ПЕНСИЯ — МЕЧТА ИЛИ СТРАШНЫЙ СОН? (v12, режиссёр)

Основа — сценарий v12. Реплики не тронуты. Справка v11: провал 5.0–6.0 с, потому что герой стоял в яме и поправлял очки. В v12 на 3.0–7.0 тело гуся летит, бьётся о стены и скользит без остановки. Пауз на месте нет ни в одном бите.

## Пластика гуся (по ней узнают без подписи)

1. Шея вытягивается вперёд и вниз в атаку, клюв открыт, шипение.
2. Крылья распахиваются рывком при испуге: один хлопок, перья веером.
3. Походка вперевалку, лапы шлёпают плоско.
4. Грудь колесом, голова высоко: важная поза.
5. Голова ныряет под воду клювом вперёд.

Антидействие: гусь умеет летать, но прыгает «по правилам» и в яме ведёт себя вежливо. Тело выдаёт натуру дважды:
- 3.0, удар о бетон: крылья рывком распахиваются для взлёта, гусь сразу складывает их по швам. Правила.
- 7.6, висит на ступеньке: крылья снова распахиваются, один хлопок, гусь снова складывает их и срывается. Второй раз не к месту: спасение было у него за спиной.
- 6.0, у лап бобра: шея уходит в атакующий выпад с шипением. Гусь гасит выпад и вежливо протягивает крыло к лопате.

Герой ярко окрашен на сером бетоне: БЕЛЫЙ домашний гусь, ярко-оранжевые клюв и лапы, красная купальная шапочка, золотая медаль «65» на красно-белой ленте. Серого гуся на серой яме не берём. Бобр: коричневый, ярко-оранжевый жилет управляющего, жёлтая каска.

## Точки внимания по высоте (маршрут оператору)

Верх вышки (0.0) → воздух (0.7–2.5) → угол брезента у бортика (2.6) → дно (3.0) → левая стена (3.3) → правая стена (4.5) → глубокая часть у лесенки (5.6) → лесенка вверх к бортику (7.0) → бортик, круг вниз (8.4) → поверхность (9.2) → верх вышки (9.6). Камере есть куда лететь: вниз, по стенам, вверх.

## Проверки

- Без звука: красивый прыжок → бетон под брезентом → лесенку уносят → круг-бублик на клюв → следующий прыгает. Шутка читается.
- Главный исход (лесенку уносят) на 7.0–8.4, не раньше. До 5 с известно только «вода — обман».
- Речевые биты: каждая реплика одним сегментом, под-биты только для действия. Слова не дробить.
- Без крови и ран: удары мультяшные, гусь отскакивает мячом, плитка трескается, гусь цел.
- Гусь серьёзен всё время. Не смеётся, не смотрит в камеру.
