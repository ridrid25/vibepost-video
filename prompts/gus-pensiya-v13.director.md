# Гусь — ТВОЯ ПЕНСИЯ — МЕЧТА ИЛИ СТРАШНЫЙ СОН? (v13, режиссёр)

Основа — сценарий v13. v11 — только справка. Провалы по замеру: на 2.0–3.0 с гусь крутился волчком на месте, на 5.0–6.0 с голова неподвижно торчала из ямы. В v13 этих картинок нет. 2.0–3.0 — удар в вращающуюся дверь, центрифуга с клерками, выстрел гуся. 5.0–6.0 — три клерка подряд прыгают над ямой, над объективом. Клерки по её замечанию живут с кадра 0 до крючка: спешат, крутятся в двери, прыгают, жалеют на бегу.

Реплики сценариста не менял. Речь: 0.6–3.3, 3.5–5.6, 5.8–7.1. Клюв свободен: зонтик и рюкзак в крыльях.

## Пластика гуся (узнают без подписи)

1. Шея змеёй: тело крутится, кувыркается, голова держится ровно и серьёзно. 0.9 под зонтиком, 2.4 в двери.
2. Шип с вытянутой шеей без повода. Первый раз на клерка в двери (2.3). Второй раз на падающие часы (7.3) — не к месту, часы не слушают.
3. Крылья рефлексом раскрываются на 0,1 с и сразу прижимаются к рюкзаку. 1.0 — мог улететь, не улетел. 7.9 из ямы — уже некуда. АНТИДЕЙСТВИЕ: птица не летит, бережёт подарок.
4. Очки съезжают на кончик клюва, он поправляет их кончиком крыла, не выпуская зонтик (4.4). Второй раз — тот же жест под часами на 8.0, поправляет очки перед смертью, как перед собранием.
5. Лапы семенят в воздухе, как по полу (0.0–0.6, 3.1 перед ударом).

## Антигерои — физический контакт с гусём

- Крот-начальник в окне 40-го этажа: машет платочком, держит настенные часы, разжимает лапы, берёт следующие. Источник кульминации.
- Клерки-звери в костюмах (заяц, барсук, енот, лиса): спешат с портфелями и кофе. В двери барсук упирается в створку и толкает её, гуся крутит центрифугой (2.2–2.8). Над ямой прыгают, лиса задевает гуся портфелем по колпаку (5.6). Заяц стучит когтем по часам-надгробию, как по наручным (8.8).
- Бобр-землекоп: подбегает с лопатой, тормозит у готовой ямы, хлопает лопатой по часам.

## Без звука

Гусь падает с башни → вместо парашюта зонтик из коктейля → бьётся в дверь офиса, клерк раскручивает её, дверь выплёвывает гуся → гусь сам выбивает себе яму → клерки жалеют его на один прыжок → землекоп опоздал → начальник бросает подарочные часы, они хоронят гуся → заяц сверяет по надгробию время → дорожка к работе — такие же часы, крот берёт следующие. Главный исход на 8.2.

## ВНИМАНИЕ по высоте

Фасад, середина (0.0) → нижние этажи (0.9) → дверь, уровень входа (2.1) → площадь, земля (3.3) → яма, ниже земли, взгляд в небо (5.0) → край ямы (6.3) → окно 40-го этажа сверху вниз до ямы (7.1–8.2) → дверь (8.8) → взлёт над площадью к окну (9.2–10.0).
