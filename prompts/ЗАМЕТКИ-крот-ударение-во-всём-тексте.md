# Крот: «переобуться весь текст» — контраст слогов ниже нормы во всех словах

16.08, ролик `fd18851d` («Крот в шляпе», замер 23.04/14.58). Татьяна нажала
кнопку правки звука и написала «переобуться весь текст».

Реплика: «О курортах мечтаю, но пока лишь под землёй. Мои путёвки — планы,
сгрызу их с тоски.» Промт — `medvedka-otpusk-fix.json`. Дубль один,
донора для пересадки нет.

## Что показал замер

Из девяти многосложных слов семь ниже нормы 2.5, у двух пик на безударном:

| слово | было | стало |
|---|---|---|
| курортах | 1.20 | 2.69 |
| мечтаю | 1.54 | 2.77 |
| пока | **0.98** (пик на «по») | 2.59 |
| землёй | 1.20 | 2.61 |
| Мои | **0.87** (пик на «Мо») | 2.63 |
| путёвки | 1.95 | 2.61 |
| планы | 2.93 | 2.93 (не трогали) |
| сгрызу | 3.07 | 3.12 (не трогали) |
| тоски | 1.28 | 2.63 |

Весь текст читался ровной интонацией. Это и есть «переобуться весь текст».

## Три грабли, на которые я наступил

**1. Равные доли слова врут.** Первый замер делил каждое слово на равное число
частей по границам whisper — и объявил, что у «планы» и «сгрызу» пик не на том
слоге. Обе тревоги ложные: деление пополам разрезало ударный гласный, и его
хвост попал в соседнюю половину. По ядрам те же слова дали 2.93 и 3.12 — их не
надо было трогать вовсе.

Мерить так: огибающая по 10 мс, сглаженная по пяти кадрам; ядро слога —
локальный максимум не ближе 70 мс к соседнему; границы — по минимумам между
ядрами.

**2. Whisper режет слово по концу гласного.** «ка» из «пока» лежало внутри метки
«лишь», «ки» из «путёвки» — внутри «планы». Отсюда и мнимый пик на первом слоге.

**3. Окно замера залезает на соседний слог.** Проверка «пик ±60 мс от ядра»
после правки дала у «Мои» 1.72 вместо 2.63: окно безударного «Мо» дотянулось до
подъёма ударного «и». Мерить внутри слога, отступив 20 мс от границы.

## Что сделано

Громкость по слогам, рампы косинусом 15 мс. Безударные ×0.35–0.75, ударные
×1.0–1.35. Пик после правки 90% шкалы. Голос не переозвучивали — губы совпадают.

```
ку .58  рор 1.30  тах .75      меч .60  та 1.12  ю .60
по .49  ка  1.30                зем .60  лёй 1.30
Мо .35  и   1.35                пу .75   тёв 1.00  ки .90
тос .63 ки  1.30
```

## Отдельно: `-shortest` срезает кадры

Первая пересборка с `-shortest` дала 237 кадров вместо 240: звук от Gemini
короче видео на 16 мс, и ffmpeg обрубил по нему — вместе с последним кадром, где
панчлайн и точка склейки петли. Флаг убрать.

Проверка, что картинка цела, одна и дешёвая:

```
ffmpeg -i файл.mp4 -an -c:v copy -f md5 -
```

MD5 видеопотока до и после совпал — значит замер картинки прежний, перемерять
нечего.

## Проверки после правки

- распознавание: те же 15 слов, сдвиг таймингов не больше 20 мс;
- контраст: ни одного слова ниже 2.5;
- видеопоток: MD5 совпадает с исходником, 240 кадров, 10.0 с.
