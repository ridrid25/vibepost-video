# Генерация роликов — «уличная экономика»

Конвейер коротких вертикальных роликов для Telegram-канала **рИИдФинанс**:
зверь с микрофоном отвечает на вопрос про деньги, деадпан, панч в конце.

Проект вырос внутри репозитория SprayCheck (историческая ветка
`claude/google-veo-video-setup-aqjvbn`) и вынесен отдельно 31.07.2026 — к
агро-приложению он отношения не имеет. Сейчас рабочая ветка этого отдельного
репозитория — `main`.

## Как это работает

Ролики попадают в постинг двумя путями, оба живые:

- **Бесплатный.** Идею придумывает бот VibePost и присылает карточкой с
  промптом. Татьяна генерирует ролик руками в приложении Gemini и отправляет
  его боту (или кладёт в папку «Ролики VibePost» на рабочем столе).
- **Платный.** `npm run reels` берёт утверждённые идеи и генерирует видео
  через Veo. Примерно 35 ₽ за ролик, нужен включённый биллинг Google.

Дальше ролик оказывается во «Входящих» приложения VibePost, где выбирается
канал и время публикации.

## Команды

| Команда | Что делает |
|---|---|
| `npm run setup` | интерактивно записывает ключ Google и настройки в `.env` |
| `npm run ideas` | Gemini предлагает концепты, вы утверждаете по одному |
| `npm run reels` | собирает ролики из утверждённых идей (Veo или свой файл) |
| `npm run video -- --prompt "..." --name "scene"` | один ролик из промпта |
| `npm run voiceover` | озвучка серии голосом Дмитрия |
| `npm run telegram:link` | привязать бота для доставки в Telegram |

## Озвучка и липсинк

`scripts/lib/dub.mjs` выбрасывает звук видеомодели и ставит бесплатный русский
голос Edge TTS (Дмитрий или Светлана), подмешивает музыку, впечатывает хук и
субтитры.

Голос подгоняется под картинку: программа находит в исходном ролике окно, где
зверь реально говорит (порог тишины считается от громкости самого ролика), и
укладывает речь в это же окно. Замедление запрещено — растянутый голос
договаривает при закрытом рте, это первое, что замечает зритель.

**Роликам из приложения Gemini озвучка обычно не нужна:** там русская речь
своя и губы совпадают идеально. Переозвучка нужна только когда голос не
устроил.

## Формат

Только вертикаль **720×1280**. В приложении Gemini формат задаётся отдельной
настройкой рядом с полем ввода — словами в промпте это не переключается,
проверено. Горизонтальный ролик приёмник VibePost сам приведёт к вертикали
с размытой подложкой, но лучше сразу снимать правильно.

## Смежный проект

Постинг живёт отдельно: **VibePost**, папка «Отложенный постинг (рассылка) в ТГ»,
репозиторий `ridrid25/vibepost`. Там же приёмник роликов `ingest-video`,
карточки идей в боте и планировщик публикаций.

Общая граница Factory Core и roadmap P1–P9 зафиксированы в
[`docs/CONTENT_FACTORY_INTEGRATION.md`](docs/CONTENT_FACTORY_INTEGRATION.md);
production prompts/settings этого репозитория остаются защищённым baseline.
