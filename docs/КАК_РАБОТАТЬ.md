# Как делать ролики

Короткая инструкция для владелицы. Технические подробности — в
[`scripts/README.md`](../scripts/README.md), ход работ — в
[`ЭТАПЫ.md`](ЭТАПЫ.md).

## Что нужно один раз

1. **Node.js 18+** — https://nodejs.org (кнопка LTS).
2. **ffmpeg** — Windows: `winget install Gyan.FFmpeg`, Mac: `brew install ffmpeg`.
3. В папке проекта: `npm install`.
4. Настройка ключа: `npm run setup` — вставить `GOOGLE_API_KEY` (ввод скрыт,
   ключ никуда не выводится).

Проверить, что всё на месте:

```
node --version
ffmpeg -version
```

## Обычный день

### Шаг 1. Придумать и утвердить тексты

```
npm run ideas
```

Gemini предложит пять концептов. Каждый показывается целиком — хук, реплика,
промпт для видео — и вы выбираете:

- **утвердить** — пойдёт в генерацию;
- **переписать** — поменять реплику и хук на свои, потом утвердить;
- **отложить** — вернуться позже (`npm run ideas -- --review`);
- **выбросить**.

Этот шаг **бесплатный**: работает только текстовая модель, видео не создаётся.

Хочется задать тему — `npm run ideas -- --brief "про отпуск и кредиты"`.
Хочется больше вариантов — `npm run ideas -- --count 10`.

Утверждённое лежит в `ideas/` обычными JSON-файлами: можно открыть и
поправить руками в любом редакторе.

### Шаг 2. Собрать ролики

```
npm run reels
```

Берёт только утверждённые идеи и делает из них готовые посты: видео → чистый
русский голос → музыка → хук → субтитры → отправка в Telegram и черновиком в
VibePost.

**Это платный шаг.** Перед первым списанием скрипт покажет смету и спросит
«да/нет». Посмотреть смету, ничего не потратив:

```
npm run reels -- --dry-run
```

Ролик 8 секунд на модели по умолчанию — примерно **$0.40**.

### Бесплатный вариант

Если не хочется платить за Veo, сделайте ролик руками в приложении Gemini,
сохраните файл под именем идеи (например `pigeon-mortgage.mp4`), положите в
папку — и:

```
npm run reels -- --source путь/к/папке
```

Всё остальное (голос, музыка, подписи, отправка) отработает так же и
бесплатно.

## Куда всё уезжает

- **Telegram** — сразу на телефон, чтобы быстро посмотреть. Включается так:
  добавить `TELEGRAM_BOT_TOKEN` в `.env`, написать своему боту любое сообщение
  и выполнить `npm run telegram:link`.
- **VibePost** — как **черновик**. Планировщик его не тронет, пока вы сами не
  выберете канал и время. Включается ключами `VIBEPOST_INGEST_URL` и
  `VIBEPOST_INGEST_SECRET` в `.env`. Это отдельный секрет приёмника;
  `service_role`-ключ Supabase для доставки роликов не нужен.

Если ключи не заданы — шаг просто пропускается, ролики всё равно лягут в
`series-output/`. Ошибка отправки никогда не роняет сборку.

## Важно про синхронизацию губ

Голос накладывается поверх готового видео: он чистый, но губы зверя двигаются
по старому ритму, поэтому идеального лип-синка не будет. Для мультяшных зверей
это обычно незаметно.

## Если что-то сломалось

- «Настройки не заданы» → `npm run setup`.
- «Не удалось запустить ffmpeg» → ffmpeg не в PATH, переустановить и открыть
  новый терминал.
- «Нет утверждённых идей» → сначала `npm run ideas`.
- Ролик собрался, но не уехал → проверить ключи в `.env`; файл при этом уже
  лежит в `series-output/`.
