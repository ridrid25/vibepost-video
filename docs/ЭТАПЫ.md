## Принятые решения

| # | Решение | Почему |
|---|---|---|
| 1 | Основной путь — **Gemini/Veo API**, автоматический | ради этого заведена ветка; владелица подтвердила 26.07 |
| 2 | Бесплатный ручной путь **сохраняем**: ролик из приложения Gemini → файл в `series-output/` → озвучка | Veo API платный, а ручная генерация в приложении бесплатна; так пайплайн полезен без биллинга |
| 3 | **VibePost остаётся**, интеграцию не выкидываем | это продуктовый выход: готовые ролики уходят туда черновиками, автопостинг планирует владелица |
| 4 | Тексты (реплики, хуки, промпты) — **только после согласования** с владелицей | юмор машина часто портит; плюс каждый прогон Veo стоит денег |
| 5 | Модель по умолчанию — `veo-3.1-lite-generate-preview`, 720p, 9:16 | самая дешёвая с нужным вертикальным форматом и звуком |

### Цена вопроса (Veo 3.1, за секунду видео)

| Модель | 720p | 1080p |
|---|---|---|
| Lite | $0.05 | $0.08 |
| Fast | $0.10 | $0.12 |
| Standard | $0.40 | $0.60 |

Ролик 8 с на Lite 720p ≈ **$0.40**. Free tier видео **не поддерживает** —
нужен платный тариф Google AI Studio. Генерация текста на flash-моделях
(`gemini-3.6-flash`) бесплатна и в биллинге не участвует.

## Сделано

### Генерация через Veo API
- `scripts/setup.mjs` — интерактивная настройка: скрытый ввод ключа, выбор
  модели, запись `.env` без затирания чужих значений, проверка ключа через
  дешёвый `models.list`.
- `scripts/generate-video.mjs` — промпт из строки или файла, поллинг операции,
  таймаут, атомарная резервация имени файла (без гонок), sidecar-JSON с
  промптом/моделью/статусом, аккуратные сообщения об ошибках.
- `scripts/lib/`: `env.mjs` (чтение/запись `.env`), `secret.mjs` (вырезание
  секретов из логов), `prompt.mjs` (ввод в терминале), `veo.mjs` (модели и
  дефолты).

### Постобработка
- `scripts/lib/polish.mjs` — ускорение 1.25×, хук-подпись сверху, субтитры
  снизу, тихая музыкальная подложка (`scripts/assets/music-bed.mp3`).

### Озвучка (бесплатно) — **проверено на реальных роликах**
- `scripts/voiceover-series.mjs` — замена ломаного русского голоса видеомодели
  на чистый Edge TTS (`ru-RU-DmitryNeural`), музыка, хук, субтитры.
- Результат: `series-output/01-raccoon-inflation.mp4`, `02-hamster-salary.mp4`,
  `03-cat-banker.mp4`.

### Доставка
- `scripts/lib/telegram.mjs` + `scripts/telegram-link.mjs` — автозахват
  `chat_id` и отправка готового ролика в Telegram.
- `scripts/lib/vibepost.mjs` — отправка в VibePost (multipart в Edge Function
  `ingest-video`), ролик приходит **черновиком**, планировщик его не трогает.

### Согласование текстов (правило №3 из `CLAUDE.md`)
- `scripts/ideas.mjs` — `npm run ideas`: Gemini предлагает концепты в стиле
  серии, владелица разбирает их по одному (утвердить / переписать реплику и
  хук / отложить / выбросить). Текстовая модель бесплатна, видео на этом шаге
  не генерируется вообще.
  Флаги: `--count N`, `--brief "пожелание"`, `--review` (разобрать отложенные).
- `scripts/lib/gemini.mjs` — обращение к `gemini-3.6-flash` со строгой JSON-схемой
  ответа, чтобы не парсить прозу. Стиль серии зашит в одном месте.
- `scripts/lib/ideas.mjs` — хранилище `ideas/YYYY-MM-DD.json`. Обычный JSON:
  можно править руками в любом редакторе. Пока `"approved": false`, генератор
  идею не видит. Слаги уникализируются — слаг становится именем файла ролика.
- Идеи **коммитятся в git**: это и есть след того, какой текст был утверждён.

### Сборка роликов из утверждённых идей
- `scripts/reels.mjs` — `npm run reels`. Берёт **только** идеи с
  `"approved": true`, у которых ещё нет видео. Два пути к исходному ролику:
  - **Veo API** — автоматически, платно. Перед первым списанием показывает
    смету (`N × ~8 с × цена модели`) и ждёт явного «да».
  - **`--source <файл|папка>`** — бесплатно: ролик, сделанный руками в
    приложении Gemini. Папка ищется по имени слага, одиночный файл годится,
    когда цель одна.

  Дальше одинаково: чистый русский голос → музыка → хук → субтитры → Telegram
  и черновик в VibePost. Собранная идея помечается `video` и `builtAt`.
  Флаги: `--only <slug>`, `--dry-run` (смета без трат), `--yes`.
- `scripts/lib/dub.mjs` — озвучка вынесена из `voiceover-series.mjs` и теперь
  работает с **любым локальным mp4**, а не только со ссылкой. Одна реализация
  вместо двух почти одинаковых.
- `scripts/lib/generate.mjs` — сам вызов Veo (submit → поллинг → скачивание),
  общий для `npm run video` и `npm run reels`, чтобы они не разъезжались.
- `scripts/lib/deliver.mjs` — общая доставка. Побочный эффект: одиночные ролики
  из `npm run video` теперь тоже уходят в VibePost, раньше только в Telegram.

**Проверено запуском 26.07:** `dubVideo` прогнан на реальном ролике из
приложения Gemini (`series-output/Формат_серии_мультяшный_D_в (1).mp4`).
Результат: 720×1280, h264 + aac, 10 с, музыка подмешана, пик звука −13.5 dB.
Сборка заняла 10 секунд. То есть бесплатный путь «готовый файл → готовый
пост» рабочий.

### Документация
- `docs/КАК_РАБОТАТЬ.md` — рабочая инструкция для владелицы: установка, обычный
  день (`ideas` → `reels`), бесплатный вариант, куда уезжают ролики, что делать
  при ошибках.
- `scripts/README.md` — техническая (англ.), с тарифами Veo и полной таблицей
  переменных `.env`.
- `scripts/ОЗВУЧКА.md` — про исторический скрипт первых трёх роликов;
  `scripts/PROMPTS.md` — 6 старых концептов зверей. Оба помечены как legacy и
  ссылаются на новый порядок.
- `CLAUDE.md` и этот журнал.

## Журнал

### 2026-07-26, вечер — первая попытка настройки
Владелица не смогла создать новый ключ в AI Studio («The request is suspicious»
— известный сбой антифрода Google, не связан с аккаунтом). Взяла существующий,
но в `.env` попала строка длиной 106 символов, начинающаяся на `AQ.` — это
токен сессии Google, а не API-ключ. Проверено прямыми запросами: и с заголовком
`x-goog-api-key`, и с `Authorization: Bearer` Google отвечает 401
`ACCESS_TOKEN_TYPE_UNSUPPORTED`.

Что из этого починено:
- `setup.mjs` теперь **проверяет ключ до записи** в `.env`. Раньше порядок был
  обратный: негодный ключ сохранялся, а потом сообщалось, что он негоден — и
  `.env` оставался отравленным.
- Сообщение об отказе стало предметным: сколько символов вставлено, похоже ли
  это на токен сессии, нет ли пробелов, и как скопировать ключ правильно.
  Сам ключ по-прежнему нигде не печатается.
- Сырой JSON от Google заменён на человеческий текст (401 / лимит / сеть).
- Убрано падение Node на Windows `Assertion failed: !(handle->flags &
  UV_HANDLE_CLOSING)` — оно возникало из-за жёсткого `process.exit()` при
  незакрытых сокетах; во всех скриптах теперь `process.exitCode`.
