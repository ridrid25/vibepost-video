# Промпты серии «Уличная экономика» — новые звери

Формат серии: мультяшный 3D в стиле Pixar, вертикаль 9:16, ~8 секунд, «уличное
интервью» (микрофон у мордочки), деадпан-взгляд в камеру, ироничный чёрный юмор
про экономику, панч в конце. Голос накладывается бесплатно через
`npm run voiceover` (голос «Дмитрий»).

Ниже — готовые концепты, придуманные до того, как появился `npm run ideas`.
Новые идеи теперь удобнее набирать через него: Gemini предлагает, вы
утверждаете, всё попадает в `ideas/` и дальше собирается через `npm run reels`
(см. [`docs/КАК_РАБОТАТЬ.md`](../docs/КАК_РАБОТАТЬ.md)).

Чтобы пустить в дело концепт отсюда, добавьте его в `ideas/` — либо руками
(JSON с полями `slug`, `animal`, `topic`, `text`, `hook`, `prompt`,
`"approved": true`), либо сгенерировав видео в приложении Gemini этим промптом
и собрав его через `npm run reels -- --source`.

## 4. 🐦 Голубь — ипотека

- **Реплика:** «Взял ипотеку на гнездо. Тридцать лет. Гнездо, кстати, из
  чужих веток.»
- **Хук:** ГДЕ ЖИВЁТ СРЕДНИЙ КЛАСС?
- **Промпт:**
  > Vertical 9:16, cute 3D animated cartoon style, Pixar-like rendering. A
  > scruffy city pigeon sits on a power line next to a messy twig nest, a tiny
  > cartoon microphone held to it. Tired deadpan look into the camera. It speaks
  > in a calm world-weary male Russian voice. On the punchline it glances at the
  > shabby nest made of random sticks. Dusk city rooftops, warm bokeh, ironic
  > dark-comedy tone, smooth animation, strong hook.
