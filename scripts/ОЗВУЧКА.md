# Озвучка серии «Уличная экономика» (бесплатный русский голос)

> Это исторический скрипт для **первых трёх** роликов серии. Новые ролики
> делаются связкой `npm run ideas` → `npm run reels` — там тексты сначала
> согласуются, а исходником может быть и готовый файл из приложения Gemini.
> См. [`docs/КАК_РАБОТАТЬ.md`](../docs/КАК_РАБОТАТЬ.md).

Готовые мультяшные ролики озвучены встроенным голосом видео-модели, а он
коверкает русский. Этот скрипт **заменяет голос на чистый русский** и делает
это **бесплатно**: озвучка синтезируется через Microsoft Edge TTS (голос
«Дмитрий») — без кредитов и без лимитов. Плюс тихая музыка, хук-подпись и
субтитры. Всё локально, на обычном компьютере (не на телефоне).

## Что нужно один раз установить

1. **Node.js 18+** — https://nodejs.org (кнопка LTS).
2. **ffmpeg** — https://ffmpeg.org/download.html
   - Windows: `winget install Gyan.FFmpeg`
   - Mac: `brew install ffmpeg`

Проверить в терминале:

```
node --version
ffmpeg -version
```

## Как запустить

В папке проекта, один раз, поставить зависимости:

```
npm install
```

Затем — сама озвучка:

```
npm run voiceover
```

Скрипт сам скачает 3 ролика, **бесплатно синтезирует голос** и склеит готовые
видео в папку **`series-output/`**:

- `01-raccoon-inflation.mp4` — енот про инфляцию 🦝
- `02-hamster-salary.mp4` — хомяк про зарплату 🐹
- `03-cat-banker.mp4` — кот-банкир про вклады 🐱

## Как подправить

В начале файла `scripts/voiceover-series.mjs`:

- `VOICE` — голос: `ru-RU-DmitryNeural` (мужской) или `ru-RU-SvetlanaNeural`
  (женский);
- `RATE` — скорость речи (`"-6%"` чуть медленнее для деадпана, `""` обычная);
- `MUSIC_VOLUME` — громкость фона (0 = без музыки);

В списке `SERIES` у каждого ролика:

- `text` — реплика (её и озвучит голос, и покажем субтитром);
- `hook` — крупная подпись сверху в первые секунды (зацеп);
- `voiceStart` — с какой секунды вступает голос (подвинь, если голос
  начинается раньше/позже, чем зверь «говорит»).

## Автоотправка (по желанию)

Если заполнить ключи в `.env`, готовые ролики после сборки сами уедут:

- **В Telegram** (тебе на телефон, для превью) — задай `TELEGRAM_BOT_TOKEN` и
  `TELEGRAM_CHAT_ID` (последний ставит `npm run telegram:link`).
- **В VibePost** (как черновик на проверку — сначала смотришь, потом сама
  выбираешь чат и время публикации) — задай `VIBEPOST_INGEST_URL` (URL Edge
  Function `ingest-video`) и `VIBEPOST_KEY` (service_role-ключ Supabase; держи
  `.env` в секрете). Ролик приходит в VibePost со статусом «черновик» и
  планировщиком не отправляется, пока ты сама его не запланируешь.

Если ключи не заданы — шаг просто пропускается, ролики всё равно лягут в
`series-output/`. Ошибка отправки никогда не роняет сборку.

## Важно про синхронизацию губ

Это простая «замена звука»: голос чистый, но губы зверя двигаются по старому
ритму видео, поэтому идеального лип-синка не будет. Для мультяшных зверей это
обычно незаметно. Идеальный лип-синк требует платной пересборки на Higgsfield
(когда вернутся кредиты).
