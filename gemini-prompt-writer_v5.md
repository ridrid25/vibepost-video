# Как писать промты для генерации видео в Gemini/Veo

Ты пишешь промты для вертикальных шортсов (9:16, 8–10 секунд) с персонажной
анимацией и русской озвучкой. Ниже — правила, выведенные из одиннадцати
итераций с замерами, а не из общих соображений. Следуй им буквально.

---

## 1. Формат: только JSON, никогда проза

Прозаический промт модель дочитывает по диагонали: начало и конец
отрабатывает, **середину теряет**. Замер на одном и том же сюжете: у прозы
секунды 1–4 держались на 15.4 из ~20 средних, у JSON с посегментным
таймлайном — 28.5. Рост 85% только от смены формата.

Причина в front-loaded взвешивании токенов: чем дальше от начала, тем меньше
вес. JSON выравнивает вес — каждый бит становится отдельным объектом, а не
абзацем в глубине текста.

**Структура промта:**

```json
{
  "duration_seconds": 10,
  "aspect_ratio": "9:16",
  "style": "...",
  "shot": { "continuity": "...", "framing": "..." },
  "subject": { "character": "...", "physicality": "...", "consistency": "..." },
  "props": { "<имя>": "...", "note": "..." },
  "environment": "...",
  "lighting": "...",
  "audio": { "language": "Russian", "delivery": "...", "pacing": "...", "lip_sync": "accurate", "sfx": [] },
  "timeline": [ { "t": "0.0-0.7", "line": "...", "action": "...", "camera": "..." } ],
  "secondary_action": "...",
  "light_events": [ { "t": "...", "event": "..." } ],
  "negative_prompt": "..."
}
```

Все описания внутри — по-английски. Реплики персонажа — по-русски, в поле
`line`. Gemini произносит русский без акцента и попадает в липсинк.

---

## 2. Таймлайн: биты по 0.6–1.2 секунды

Один сегмент = одно физическое событие. Никогда не оставляй сегмент длиннее
1.5 секунды: на длинной реплике модель уходит в говорящую голову и динамика
проваливается.

Длинную фразу **режь на два-три сегмента** и в каждый клади отдельное
действие. Проверено: разрезание первой фразы на три бита подняло мёртвую зону
вдвое.

```json
{"t": "0.7-1.6", "line": "Вчера видел бамбук", "action": "..."},
{"t": "1.6-2.4", "line": "по четыреста рублей", "action": "..."}
```

## 3. Пластика героя — источник всех гэгов

**Делай это до таймлайна.** Выпиши 4–6 характерных движений персонажа —
таких, по которым его узнают без подписи. Гэги берутся из них, а не
сочиняются отдельно. Ролик со случайными трюками смотрится как набор
аттракционов; ролик, где трюки растут из природы героя, читается как характер.

Источник — реальное поведение животного или типажа, а не защищённый
мультперсонаж. Копировать узнаваемую внешность и повадки чужого героя нельзя,
а повадки настоящего животного не принадлежат никому.

| Герой | Характерная пластика |
|---|---|
| Панда | чешется спиной о любой столб, садится враскоряку с вытянутыми лапами, кувыркается назад, ковыряется, роняет то, что держит |
| Ленивец | всё с задержкой — реакция приходит через секунду после события; цепляется, а не держит; моргает медленнее, чем говорит |
| Кот | после падения делает вид, что так и задумано, и начинает умываться; сбрасывает предметы лапой, глядя в объектив |
| Пёс | не может стоять на месте, виляет всем корпусом, бросает реплику на полуслове ради постороннего звука |
| Пингвин | ходит переваливаясь, скользит на животе, спотыкается на ровном месте |
| Сова | корпус неподвижен, поворачивается только голова; замирает целиком в момент, требующий движения |
| Капибара | абсолютная невозмутимость при любом хаосе вокруг — гэг строится на том, что она не реагирует |
| Хомяк | набивает щёки и продолжает говорить; прячет за щеку то, что нельзя прятать |

Правила использования:

- **Один жест — один бит.** Не сваливай два движения в один сегмент.
- **Повтори один жест дважды за ролик**, второй раз — в неподходящий момент.
  Повтор превращает трюк в характер: панда чешется о столб на шутке и снова
  чешется, когда ей сообщают плохую новость.
- **Жест должен ломать равновесие**, а не сопровождать реплику. Сопровождающий
  жест модель проигнорирует, ломающий — отработает.
- **В поле `subject` вынеси их явно:**

```json
"subject": {
  "character": "...",
  "physicality": "rubbery soft-body weight, belly and fur overshoot on every impact",
  "characteristic_moves": "scratches his back against any post, sits splay-legged with hind legs straight out, tumbles backwards, fumbles whatever he holds",
  "consistency": "same character in every segment, no costume changes"
}
```

Если герой не животное, а типаж — охранник, бариста, таксист — принцип тот же:
выпиши, что он делает руками в простое. Именно эта мелочь и опознаётся.

### Антидействие — гэг от противного

Второй мотор, сильнее первого: герой делает то, что ему **совершенно не
свойственно**. Корова на пуантах в балетной пачке. Медведь, аккуратно
складывающий оригами. Крокодил, вяжущий крючком.

Работает при трёх условиях, иначе выходит не шутка, а случайность:

1. **Природа показана до слома.** Первый бит — герой тяжёлый, неуклюжий,
   роняет. И только потом безупречный фуэте. Смешна разница, а её не с чем
   сравнить, если натуру не показали.
2. **Тело продолжает выдавать натуру.** Корова танцует чисто, но пол трясётся,
   с потолка сыплется штукатурка, пуанты трещат. Полное превращение убивает
   гэг — держи один признак исходной природы.
3. **Герой абсолютно серьёзен.** Он не понимает, что делает что-то странное.
   Как только персонаж подмигивает зрителю, шутка исчезает.

В JSON это отдельное поле рядом с характерной пластикой:

```json
"subject": {
  "characteristic_moves": "heavy hooves, sways when standing, chews constantly",
  "anti_action": "rises onto pointe shoes and performs a flawless pirouette with perfect ballet posture, utterly serious, while the floorboards crack and dust falls from the ceiling"
}
```

Готовые связки природа → антидействие:

| Герой | Что показать сначала | Антидействие |
|---|---|---|
| Корова | тяжесть, покачивание, жвачка | безупречный балет на пуантах |
| Медведь | грубая сила, ломает всё, что берёт | складывает оригами двумя когтями |
| Ленивец | всё с задержкой | внезапно печатает вслепую со скоростью стенографистки |
| Слон | масса, топот | ходит по тонкому льду, ни звука |
| Крокодил | зубы, резкость | вяжет крючком, считает петли вслух |
| Панда | лень, неуклюжесть | ведёт бухгалтерию на счётах молниеносно |

**Куда ставить — решай сам**, исходя из героя и удержания. Жёсткого правила
нет, есть размен:

- **Ближе к началу** — сильнее хук, зритель остаётся ради «что это было». Но
  природу героя придётся показать одним битом, буквально за полсекунды, и слом
  сработает только если пластика читается мгновенно: тяжесть коровы видна
  сразу, а замедленность ленивца — нет.
- **В переломе** — антидействие становится поворотом сюжета, а не украшением.
  Годится, когда природу нужно показать основательно.
- **В добивке** — самый сильный панч и лучший повод пересмотреть, но зритель
  должен досидеть. Требует, чтобы удержание держалось на чём-то другом.

Проверь себя вопросом: **успел ли зритель понять природу героя к моменту
слома?** Если нет — двигай позже или показывай природу резче. Если природа
очевидна с первого кадра — двигай раньше и забирай хук.

## 4. Динамику даёт предмет, а не камера

Это главный вывод. Три захода подряд с усложнением операторской работы —
whip-pan, snap-zoom, rack focus, уход из кадра — **не дали ничего**, прирост
в пределах шума. Секунда с предметом в руках выросла втрое.

Правило: **камеру вешай туда, где уже есть физическое событие.** Она усиливает
происходящее, но не создаёт его.

Предмет должен:
- **вводиться действием** — не появляться из ниоткуда. Траву надо вырвать из
  трещины в асфальте, а не обнаружить во рту;
- **вестись через весь ролик** — если герой спрятал палку на 8-й секунде, на
  9-й она не может быть снова в лапе;
- **отыгрывать дважды** — введён в начале, возвращается в финале другим
  смыслом. Это то, ради чего пересматривают.

## 5. Второстепенный персонаж — лекарство от статики

Там, где герой по драматургии неподвижен (сидит, молчит, осознаёт), добавить
ему действие нельзя — оно сломает сцену. Вместо этого добавляй движение
вокруг него.

```json
"secondary_action": "a hurrying passer-by steps square on his hind paw without looking and walks on. He does not react at first, then slowly looks down at the paw"
```

Работает только **физический контакт** с героем. Размытые прохожие на фоне не
дают ничего — проверено, ноль прироста.

Задержанная реакция сильнее мгновенной: зритель замечает событие раньше
персонажа.

Варианты: фонарь падает на голову, вывеска искрит и гаснет, лужа окатывает
водой, из окна что-то выбрасывают, собака утаскивает реквизит.

---

## 6. Свет — отдельным полем

В общем описании освещения световые события тонут. Выноси их в таймлайн:

```json
"light_events": [
  {"t": "1.6-2.4", "event": "headlights of a passing car sweep across him left to right, his shadow stretching along the wet asphalt"},
  {"t": "5.0-7.0", "event": "the neon sign above him flickers in a broken loop, strobing his face between cyan and darkness"}
]
```

В базовом `lighting` всегда задавай контровой свет с двух сторон разного
цвета — он обводит силуэт и вытаскивает персонажа из фона. Плоский фронтальный
свет делает картинку тусклой независимо от разрешения.

---

## 7. Камера: необычные ракурсы формулировками, которые модель понимает

- из глаза — `extreme macro on his eye, pulling out through the reflection in it to reveal the whole scene`
- из затылка — `starts behind his head, orbiting around the skull to his face`
- сверху — `top-down overhead shot looking straight down at him on the wet asphalt`
- из-под ноги — `camera embedded in the asphalt at ground level, looking up as his paw comes down over the lens`

Последний особенно силён для хука: лапа накрывает объектив, экран темнеет.

**Осторожно:** JSON исполняется буквально. Написал `static-ish` — получишь
статику. Написал `brief loss of frame` — получишь склейку. Проза такие
формулировки сглаживала, структура исполняет дословно.

---

## 8. Непрерывность плана

Без явного запрета модель нарежет ролик на 3–5 склеек. Если нужен один план:

```json
"shot": {
  "continuity": "single continuous take, one uninterrupted camera move, no cuts, no shot changes, no editing transitions",
  "framing": "character stays in frame at all times"
}
```
и в негатив: `cuts, shot changes, editing transitions, jump cuts`.

Но взвешивай: цельность против динамики. Для десятисекундного шортса **ровная
динамика важнее непрерывности** — три склейки зритель не заметит, а мёртвую
секунду чувствует сразу.

---

## 9. Текст в кадре

По умолчанию текст запрещён — модели любят вжигать кривые подписи. Но если
текст на предмете нужен по сюжету (ценник, табличка, вывеска), опиши его в
`props` как физический реквизит и **убери общий запрет**, оставив только
служебный:

```json
"props": {
  "price_tag": "handwritten and clearly readable: 400 ₽. A physical prop inside the world, not an overlay"
},
"negative_prompt": "subtitles, captions, watermark, text overlay, burned-in graphics, ..."
```

Цифры на объектах рисуются нестабильно — короткие числа надёжнее длинных, при
неудаче меняй сид, а не формулировку.

---

## 10. Отрицания превращай в утверждения

Модель плохо понимает «предмета нет» и хорошо — «лапы пустые».

Плохо: `the stick is gone`
Хорошо: `both paws are empty — the stick is hidden under his t-shirt and not visible`

---

## 11. Темп речи

Модель тянет реплики. Задавай темп в трёх местах сразу — иначе не сработает:

```json
"audio": {
  "delivery": "fast, clipped, weary deadpan",
  "pacing": "rapid delivery, no drawn-out words, tight gaps between lines, all lines fit their segments with room to spare"
}
```
плюс `spoken fast` в начале каждого `action` с репликой, плюс `slow speech,
drawn-out delivery` в негатив.

---

## 12. Драматургия десяти секунд

- **0.0–0.7 хук.** Не заголовок, а физическое событие. Герой влетает в кадр,
  падает, что-то роняет. Первые полторы секунды решают удержание.
- **0.7–5.0 развитие.** Каждая реплика подпирается гэгом, ломающим равновесие
  героя — поскользнулся, уронил, промахнулся.
- **5.0–7.0 перелом.** Смена регистра: смех обрывается, герой садится на землю.
  Здесь вступает второстепенный персонаж.
- **7.0–8.0 пауза.** Молчание и взгляд в объектив. Обязательно дать герою
  мелкое действие, иначе провал.
- **8.0–10.0 добивка.** Панч плюс визуальный гэг. Последний кадр должен
  содержать деталь, ради которой пересматривают.

**Неожиданный поворот** ищи не в реплике, а в предмете: он должен оказаться не
тем, чем казался, или вернуться в финале с обратным смыслом.

---

## 13. Обязательный негатив

```
slow speech, drawn-out delivery, subtitles, captions, watermark, text overlay,
burned-in graphics, English speech, foreign accent, static camera,
locked-off shots, floating objects, duplicate props, object duplication,
extra limbs, multiple characters, character changing appearance mid-shot
```

`duplicate props` и `floating objects` — не перестраховка: без них модель
дорисовывает второй экземпляр реквизита и подвешивает предметы в воздухе.
Обе ошибки встречались.

---

## 14. Проверка результата замером, а не на глаз

После генерации считай динамику: покадровая разница яркости при 12 fps,
усреднённая по секундам.

```bash
ffmpeg -i video.mp4 -vf "fps=12,scale=240:-1" f/%03d.png
# затем среднее |кадр[i+1] - кадр[i]| по каждой секунде
```

На что смотреть:
- **средняя динамика** — ориентир 20+ для слапстика;
- **худшая секунда** — важнее средней. Цель: ни одной секунды ниже 10.
  Удержание ломается на провалах, а не на невысоком среднем;
- **число резких склеек** — скачок разницы выше 45.

Провал в конкретной секунде показывает, какой сегмент промта переписывать.
Так чинится адресно, а не наугад.

---

## 15. Чего делать не надо

- Не описывай камеру там, где нет события — не поможет.
- Не пиши общими словами «динамично», «энергично», «выразительно» — модель их
  игнорирует. Только конкретные физические действия.
- Не оставляй сегмент без `action`, даже если там пауза.
- Не полагайся на то, что модель сама свяжет соседние биты — прописывай
  переход явно (`pulls out fast from the tag into a wide arc`).
- Не проси немую генерацию, если нужна русская речь: Gemini произносит русский
  чисто, а отдельная озвучка ломает липсинк.

## 16. Скрипт замера

Положи рядом как `measure.py` и запускай после каждой генерации:
`python measure.py video.mp4`

```python
#!/usr/bin/env python3
"""Замер динамики ролика: среднее, худшая секунда, склейки."""
import glob, os, shutil, subprocess, sys
import numpy as np
from PIL import Image

v = sys.argv[1]
tmp = "_m"
shutil.rmtree(tmp, ignore_errors=True); os.makedirs(tmp)
subprocess.run(["ffmpeg", "-hide_banner", "-loglevel", "error", "-y", "-i", v,
                "-vf", "fps=12,scale=240:-1", f"{tmp}/%03d.png"], check=True)
fr = [np.asarray(Image.open(f).convert("L"), float) for f in sorted(glob.glob(f"{tmp}/*.png"))]
d = [np.abs(fr[i+1] - fr[i]).mean() for i in range(len(fr) - 1)]
sec = [float(np.mean(d[s*12:(s+1)*12])) for s in range(len(d)//12)]
cuts = [round(i/12, 1) for i, x in enumerate(d) if x > 45]

for i, m in enumerate(sec):
    print(f"{i}-{i+1}с  {m:5.1f}  {'#' * int(m*2)}")
print(f"\nсреднее      {np.mean(d):5.2f}   (ориентир 20+)")
print(f"худшая сек   {min(sec):5.2f}   (цель: не ниже 10)")
print(f"склеек       {len(cuts):5d}   {cuts}")
worst = sec.index(min(sec))
print(f"\nпереписывать сегмент {worst}.0-{worst+1}.0 — там провал")
shutil.rmtree(tmp, ignore_errors=True)
```

Читай вывод так: **худшая секунда важнее средней.** Если она ниже 10 — иди в
таймлайн, найди сегмент с этим временем и добавь туда физическое действие или
второстепенного персонажа. Если склеек больше трёх и нужен цельный план —
проверь, нет ли в промте формулировок вроде `whip-pan`, `brief loss of frame`,
`snap-zoom`, они провоцируют рез.

## 17. Порядок работы

1. Написать JSON по разделам 1–12.
2. Сгенерировать в Gemini, формат 9:16.
3. Прогнать `measure.py`.
4. Если худшая секунда ниже 10 — переписать **только** провалившийся сегмент,
   остальные не трогать. Одна правка за итерацию, иначе не понять, что помогло.
5. Повторять, пока провалов нет.

Не меняй несколько сегментов сразу и не переписывай промт целиком — так
теряется причинно-следственная связь, и итерации превращаются в угадывание.
